# Detail pass comparisons

Each `*_vs_*.jpg` puts a Wikimedia Commons photograph (left) beside a NightView render from the matching position (right). Credits are printed under each image and listed in `RESEARCH/reference/commons/ref-commons-meta.json`. Where the left photo is CC BY-SA, the combined image is shared under the same licence. No Google imagery is used.

`*_driver_eye.jpg` are in-game views at driver's eye height (1.2 m) with the HUD visible; `arch_statue_closeup.jpg` is the War group from the plaza.
