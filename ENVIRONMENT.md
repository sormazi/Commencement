# Environment

The corridor reclamation pipeline (`dist/environment.js`, with facade collapse in `destruction.js` and `aftermath.js`) belonged to the Times Square, SoHo and Shibuya locations and was removed with them in Step 10. It remains in git history and on the main branch.

Washington Square's decay is a separate runtime layer on top of the clean 2026 campus, blendable between 2026 and 2126: `dist/campus/atmosphere/decay.js` (material decay kinds for masonry, glass, metal, paving, facades, cloth, lights and the van's paint), overgrowth, tree growth, lamps, fog and crowds all read the same value. It is described in CAMPUS.md.
